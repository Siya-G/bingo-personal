# Frontend

Next.js frontend for the AI Bingo application using TypeScript and the App Router.

## Folder Purpose

- `app/` - Next.js App Router routes, layouts, and global styles.
- `components/` - Reusable UI components.
- `lib/` - Shared client utilities, API clients, and framework helpers.
- `types/` - Shared TypeScript types and interfaces.
- `hooks/` - Reusable React hooks.

This app is scaffolded without business logic so product flows can be added incrementally.

## Local Setup

```bash
npm install
npm run dev
```

## Tests

```bash
npm run test
```

See `tests/README.md` for what each spec covers.
